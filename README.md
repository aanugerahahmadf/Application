# Fleur Décor — Wedding Flowers Decoration Mobile App

Modern glassy wedding editorial Android mobile application built with **Kotlin** and **Jetpack Compose**, featuring **Content-Based Image Retrieval (CBIR)** visual flower search, tiered wedding decoration packages, interactive consultations, and booking management.

## 🌸 Core Features

- **Modern Glassy Wedding Editorial UI:** Translucent frosted surfaces, warm ivory/blush/champagne/lavender gradients, WCAG AA charcoal typography, and locally bundled **Instrument Sans** typography.
- **Visual Flower Search (CBIR):** Camera and gallery image retrieval system that analyzes floral arrangements, color palettes, and density to return similarity-scored wedding decoration results.
- **Curated Catalog & Tier Packages:** Detailed view of wedding altars, arches, table centerpieces, and bridal bouquets with tiered options (Silver, Gold, Platinum).
- **Cart & Booking Checkout:** Tier selection, date picker, venue address, notes, discount vouchers, and live price breakdowns.
- **Orders & Payment Instructions:** Order tracking timeline, Virtual Account copy with 24-hour countdown, QRIS scan display, and proof of transfer upload.
- **Identity Verification (KYC):** Guided document scanner (KTP, SIM, NPWP, Passport) and circular selfie guide with biometric liveness scoring.
- **Live Consultation & Chat:** In-app floral designer messaging with photo attachments and simulated live video consultation call.
- **Account Switcher & App Lock:** Floating bottom navigation capsule with quick double-tap account switching, long-press account modal sheet, and 4-digit PIN security lock.
- **Multi-Language & Appearance:** Bilingual support (Indonesian & English) and theme modes (Light, Dark, and System).
